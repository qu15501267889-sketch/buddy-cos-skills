# 保留原背景模式（不换场景）

> 用户说「背景太乱 / 背景里有人 / 把灯架去掉 / 后面那些杂物清一下」，但**没有说要换场景**时，用本模板。
> 跟 `scenes.md` 的区别：`scenes.md` 是**整个背景板换掉**；本模板是**这个场地本身留着，只把它弄干净**。

## 判定

| 他说 | 走哪条 |
|---|---|
| 「换成卧室 / 雪境 / 舞台」 | `scenes.md` 换场景 |
| 「背景太乱 / 有人 / 灯架去掉 / 清干净」「别换背景」 | 本模板 |
| 没说背景相关的事 | 什么都不做，别自己加 |

**关键**：场馆的透视、地面、建筑结构、柱梁、EXIT 牌——**全部保留**。只清走人、灯具、电线、杂物、水渍。他要的是「这个场地就我一个人」，不是「换个场地」。

## 四件套固定配方

不换场景时，按这个顺序组四块，缺一不可（他认可过的组合）：

1. **清杂物** —— 人、灯架、柔光箱、反光板、电线、水渍、垃圾
2. **主角灯** —— 给人物一束集中追光，背景相对压暗，人从背景里拔出来
3. **轻特效** —— 轻档，只做氛围（光尘 / 薄雾 / 粒子），不抢主体
4. **坐具换云朵** —— 坐姿时把原来的凳子/箱子/毛毯换成云朵承托

## 模板

```text
处理内容：
1. <面部精修：逐字引 portrait.md>
2. 清理背景：移除背景里的灯架、柔光箱、反光板、电线、以及所有其他人员，地面水渍与垃圾清除，画面中只有这一位人物与干净的场地；场地的空间结构、地面与建筑轮廓保持原样
3. 主角灯光：一束柔和而集中的主角追光从侧上方打亮人物，人物在光束中明亮突出，背景相对压暗，光束边缘有细腻的体积光
4. <坐姿时>坐在一团蓬松柔软的白色云朵上，云朵边缘自然翻卷、质地绵密有细微明暗起伏，承托身体重量微微下凹
5. 轻特效：空气中漂浮着零星细小的光尘，淡淡的薄雾贴着地面，若有若无融入画面，克制低调
```

## 坐具换云朵写法

- **旧坐具一个字都不提**（见 SKILL.md §4 存在性锚定）。
- 弱：「把椅子换成云朵」→ 椅子和云都画，或者都消失。
- 强：「坐在一团蓬松柔软的白色云朵上，云朵边缘自然翻卷、质地绵密有细微明暗起伏，承托身体重量微微下凹」。
- 云朵颜色配他服装主色：冷色系→白/淡蓝；暖色系→米白/暖白。
- 悬空感要压住：云朵底部要有**与地面接触的阴影**，否则人物像贴在背景上。

## 轻特效的边界

「轻」指的是**不改变画面结构**，不是「弱到看不见」：
- 可以有：光尘、薄雾、地面反光、体积光、细小雨丝
- 不要有：柱状光幕、大范围粒子风暴、发光纹路、地面图案
- 不加法阵/符文/光环（SKILL.md §4 特效禁令）

## 验收坑

**vision 会把保留的建筑结构报成「清理未完成」**（水泥柱、横梁、EXIT 牌、地面接缝）。
验收准绳是**用户口径**：人和灯具清空 = 达标。建筑结构本来就要留，不要因为它报错就再跑一遍。

## 禁止

- 清杂物的同时改透视线、地面线、相机角度
- 顺手把背景墙刷成别的颜色（那是换场景）
- 顺手改人物姿势或服装
- 背景里留下原场景的残留（半截灯架、半个人、电线尾巴）
